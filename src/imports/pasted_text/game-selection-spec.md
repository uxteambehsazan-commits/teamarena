============================================================
GAME SELECTION — 1 TO 4 GAMES
PRODUCT: «میدان هم‌تیمی‌ها»
============================================================

بخش «انتخاب بازی‌ها» را اصلاح کن تا کاربر بتواند:

MINIMUM: 1 GAME
MAXIMUM: 4 GAMES

انتخاب کند.

کاربر نباید مجبور باشد چند بازی انتخاب کند.

می‌تواند فقط یک بازی را انتخاب کند و بازی را شروع کند.

============================================================
1. SELECTION RULE
============================================================

کاربر مجاز است:

✓ 1 بازی
✓ 2 بازی
✓ 3 بازی
✓ 4 بازی

انتخاب کند.

بیش از 4 بازی مجاز نیست.

یعنی:

1 ≤ selectedGames ≤ 4

============================================================
2. GAME SLIDER
============================================================

همان ساختار Slider فعلی حفظ شود.

در هر لحظه فقط یک Game Artwork اصلی نمایش داده شود.

کاربر بتواند با:

- Swipe روی تصویر
- Drag
- فلش چپ
- فلش راست

بین بازی‌ها حرکت کند.

جهت فلش‌ها در RTL باید صحیح باشد و به سمت منطقی حرکت Slider اشاره کند.

============================================================
3. SELECT CURRENT GAME
============================================================

زیر اطلاعات بازی یک CTA واضح قرار بده:

«✓ انتخاب این بازی»

وقتی کاربر روی آن کلیک می‌کند:

Game فعلی به Selected Games اضافه شود.

بعد از انتخاب:

Button State تغییر کند به:

«✓ انتخاب شد»

یا یک State واضح مشابه.

از دکمه‌ای با مفهوم «حذف انتخاب» در محل CTA اصلی استفاده نکن.

حذف فقط از طریق × روی Chip انتخاب‌شده انجام شود.

============================================================
4. SELECTED GAME CHIPS
============================================================

بخش:

«بازی‌های انتخاب‌شده»

در بالای بخش Slider یا در یک ناحیه Sticky و قابل مشاهده قرار بگیرد.

مثلاً:

بازی‌های انتخاب‌شده: 3 از 4

[⚡ اسم‌فامیل ×]
[🕵️ حدس بزن ×]
[😉 چشمک ×]

هر Chip شامل:

- Icon بازی
- نام کوتاه بازی
- × برای حذف

باشد.

وقتی کاربر روی × کلیک کرد:

آن بازی از Selected Games حذف شود.

و دوباره امکان انتخاب آن بازی فراهم شود.

============================================================
5. SELECTION COUNTER
============================================================

یک Counter واضح نمایش بده:

«۱ از ۴ بازی انتخاب شده»

یا:

«۲ از ۴ بازی انتخاب شده»

یا:

«۳ از ۴ بازی انتخاب شده»

یا:

«۴ از ۴ بازی انتخاب شده»

این Counter باید با هر انتخاب و حذف بلافاصله Update شود.

6. WHEN ONE GAME IS SELECTED
============================================================

اگر فقط یک بازی انتخاب شده:

نمایش بده:

«۱ بازی انتخاب شده»

و CTA اصلی:

«🚀 بزن بریم!»

فعال باشد.

کاربر بتواند بدون انتخاب بازی دوم، سوم یا چهارم بازی را شروع کند.

IMPORTANT:

یک بازی کافی است.

CTA:

8. WHEN THREE GAMES ARE SELECTED
============================================================

نمایش:

«۳ از ۴ بازی انتخاب شده»

CTA:

«🚀 بزن بریم!»

فعال باشد.

============================================================
9. WHEN FOUR GAMES ARE SELECTED
============================================================

نمایش:

«۴ از ۴ بازی انتخاب شده»

CTA:

«🚀 بزن بریم!»

فعال باشد.

وقتی 4 بازی انتخاب شده است:

هیچ بازی پنجم قابل انتخاب نباشد.

دکمه «انتخاب این بازی» برای بازی‌های انتخاب‌نشده Disabled شود.

اما کاربر همچنان بتواند:

- بازی‌های انتخاب‌شده را حذف کند.
- ترتیب بازی‌ها را در صورت پشتیبانی سیستم تغییر دهد.
- بازی‌های Slider را مشاهده کند.

============================================================
10. FIFTH GAME ATTEMPT
============================================================

اگر کاربر در حالی که 4 بازی انتخاب شده است بخواهد بازی پنجم را انتخاب کند:

نباید هیچ انتخابی انجام شود.

یک پیام کوتاه و دوستانه نمایش بده:

«۴ بازی انتخاب کردی؛ برای انتخاب این بازی، اول یکی از انتخاب‌هات رو حذف کن. 🙂»

یا:

«حداکثر ۴ بازی می‌تونی انتخاب کنی.»

پیام باید:

- کوتاه
- واضح
- دوستانه

باشد.

============================================================
11. GAME CHIP DELETE
============================================================

روی × هر Chip:

Click
→ Remove Game
→ Update Counter
→ Update Selection State
→ Enable Game Selection Again

مثلاً:

4 از 4

بعد از حذف:

3 از 4

و بازی حذف‌شده دوباره قابل انتخاب شود.

============================================================
12. DUPLICATE PREVENTION
============================================================

یک بازی نباید دوبار انتخاب شود.

اگر بازی قبلاً انتخاب شده است:

Button:

«✓ انتخاب شد»

باشد.

Click دوباره نباید آن را دوباره به لیست اضافه کند.

============================================================
13. ORDER OF SELECTED GAMES
============================================================

ترتیب انتخاب بازی‌ها اهمیت دارد.

مثلاً اگر کاربر این ترتیب را انتخاب کرد:

1. حدس بزن
2. چشمک
3. جاسوس
4. اسم‌فامیل سرعتی

ترتیب اجرای بازی‌ها نیز:

حدس بزن
→ چشمک
→ جاسوس
→ اسم‌فامیل سرعتی

باشد.

در Chipها شماره ترتیب نیز نمایش داده شود:

① حدس بزن ×
② چشمک ×
③ جاسوس ×
④ اسم‌فامیل سرعتی ×

اگر سیستم فعلی قابلیت Reorder دارد، امکان Drag & Drop برای تغییر ترتیب نیز فراهم کن.

اگر Reorder در Game Engine وجود ندارد، آن را به صورت Fake UI اضافه نکن.

22. GAME ENGINE INTEGRATION
============================================================

Selection UI باید فقط View لایه Game Selection باشد.

State واقعی:

selectedGames[]

باید منبع حقیقت باشد.

قوانین:

if selectedGames.length === 0:
Start disabled

if selectedGames.length >= 1:
Start enabled

if selectedGames.length >= 4:
New selections blocked

if game already selected:
Prevent duplicate

if game removed:
Return to available state
