============================================================
MASTER MOBILE HEADER REDESIGN
PRODUCT: «میدان هم‌تیمی‌ها»
============================================================

IMPORTANT:
مشکل Header فقط مربوط به یک صفحه نیست.

در کل اپلیکیشن، Header در نسخه موبایل بیش از حد شلوغ،
متراکم و کم‌خوانا است.

Screenshot پیوست‌شده را به عنوان نمونه اصلی مشکل در نظر بگیر.

این مشکل باید به صورت SYSTEM-WIDE حل شود، نه فقط در یک صفحه.

تمام Headerهای موبایل اپلیکیشن را Audit و سپس بازطراحی کن.

============================================================
PRIMARY OBJECTIVE
============================================================

هدف:

CREATE ONE CONSISTENT MOBILE HEADER SYSTEM

که در تمام صفحات اپلیکیشن استفاده شود.

Header موبایل باید:

- ساده
- خلوت
- خوانا
- سریع‌الفهم
- Premium
- مدرن
- مناسب RTL
- مناسب Touch
- Responsive

باشد.

اصل اصلی:

DO NOT FIT MORE INFORMATION INTO THE HEADER.

INSTEAD:

REDUCE
→ PRIORITIZE
→ GROUP
→ MOVE SECONDARY INFORMATION OUT OF HEADER

============================================================
NEW MOBILE HEADER PRINCIPLE
============================================================

در موبایل Header باید فقط اطلاعات و Actions ضروری همان صفحه
را نمایش دهد.

قاعده:

ONE HEADER
+
ONE PRIMARY PURPOSE
+
MAXIMUM 1–2 ACTIONS

از قرار دادن تعداد زیادی Button و Icon در Header خودداری کن.

============================================================
HEADER HEIGHT
============================================================

Header نباید فضای زیادی از صفحه را اشغال کند.

ارتفاع Header موبایل را Compact نگه دار.

اما:

COMPACT ≠ CRAMPED

بین عناصر فضای کافی وجود داشته باشد.

Header نباید به دلیل کوچک شدن ارتفاع،
فونت‌ها و آیکن‌ها را بیش از حد کوچک کند.

- حداکثر یک Action ضروری

- Score

در Content به صورت Card / Section نمایش داده شوند.

2. REMOVE REDUNDANT BRANDING
============================================================

در Screenshot:

لوگو + نام برند + نام محصول + شعار

همزمان در Header نمایش داده شده‌اند.

این کار در موبایل باعث تراکم می‌شود.

در Header موبایل فقط یکی از این‌ها را به عنوان Primary Brand Identity
نمایش بده.

مثلاً:

لوگو + «میدان هم‌تیمی‌ها»

و شعار:

«چند دقیقه دورهمی، کلی رقابت»

در Header نمایش داده نشود.

در صورت نیاز در Home Hero یا صفحه اصلی نمایش داده شود.
