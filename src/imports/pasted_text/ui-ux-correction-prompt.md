==================================================
1. اصلاح جهت فلش‌های اسلایدر
==================================================

در صفحه فعلی، فلش‌های دو طرف تصویر بازی جهت اشتباهی دارند.

الان:
- فلش سمت چپ به سمت راست اشاره می‌کند.
- فلش سمت راست به سمت چپ اشاره می‌کند.

این مورد را اصلاح کن.

رفتار صحیح:
- فلش سمت چپ صفحه باید «←» باشد و کاربر را به بازی قبلی ببرد.
- فلش سمت راست صفحه باید «→» باشد و کاربر را به بازی بعدی ببرد.

قانون:
LEFT ARROW = previous game
RIGHT ARROW = next game

فلش‌ها باید کاملاً RTL-friendly باشند.

با کلیک روی فلش:
- اسلاید بازی با انیمیشن نرم جابه‌جا شود.
- تصویر بازی قبلی خارج شود.
- تصویر بازی بعدی وارد شود.
- عنوان، توضیحات و اطلاعات بازی همزمان با تصویر تغییر کند.
- بازی انتخاب‌شده فعلی حفظ شود.
- وضعیت انتخاب بازی‌ها با تغییر اسلاید از بین نرود.

برای Touch:
- Swipe Right = previous game
- Swipe Left = next game

حرکت Swipe باید روی خود تصویر/ناحیه Hero بازی فعال باشد.

2. انتقال دکمه «بزن بریم!» به انتهای صفحه
==================================================

دکمه اصلی «🚀 بزن بریم!» نباید در بالای صفحه قرار داشته باشد.

این دکمه را به انتهای صفحه و بعد از بخش انتخاب بازی‌ها منتقل کن.

ساختار پایین صفحه:

[Selected Games / Chips]
        ↓
[🚀 بزن بریم!]

دکمه باید:
- در پایین‌ترین بخش محتوای صفحه قرار بگیرد.
- همیشه در دسترس باشد.
- با طراحی Premium فعلی هماهنگ باشد.
- همان افکت نور/Stroke متحرک فعلی را حفظ کند.
- CTA اصلی صفحه باشد.

متن دکمه:
«🚀 بزن بریم!»

اگر هیچ بازی انتخاب نشده:
- دکمه غیرفعال باشد.
- ظاهر آن همچنان زیبا باشد ولی مشخصاً Disabled state داشته باشد.
- Tooltip / helper text:
«حداقل یک بازی را انتخاب کن»

وقتی حداقل یک بازی انتخاب شد:
- دکمه فعال شود.
- افکت Glow و Animated Stroke فعال شود.

4. نوار بازی‌های انتخاب‌شده — CHIP SYSTEM
==================================================

هر بازی که کاربر انتخاب می‌کند باید به صورت یک CHIP در نوار بالای تصویر نمایش داده شود.

مثال:

[🧩 کلمه ممنوعه ×]
[⚡ اسم‌فامیل سرعتی ×]
[🕵️ جاسوس ×]

هر Chip شامل:
- آیکن بازی
- نام کوتاه بازی
- دکمه × برای حذف

علامت × به معنی:
«حذف بازی از لیست انتخاب‌شده‌ها»

است.

وقتی کاربر روی × کلیک کرد:
- بازی از لیست انتخاب‌شده حذف شود.
- Chip با یک انیمیشن کوچک و نرم حذف شود.
- تعداد بازی‌های انتخاب‌شده در Header به‌روزرسانی شود.
- اگر بازی حذف‌شده همان بازی فعلی Slider بود، خود Slider به صورت خودکار بازی را حذف نکند؛ فقط Selection state آن بازی تغییر کند.
- دکمه «انتخاب این بازی» دوباره برای آن بازی نمایش داده شود.

IMPORTANT:
× فقط باید Selection را حذف کند، نه اینکه بازی را از کل سیستم یا لیست بازی‌ها حذف کند.

5. دکمه انتخاب بازی
==================================================

دکمه فعلی:

«✓ انتخاب حذف»

اشتباه است و باید به یک CTA انتخاب تبدیل شود.

متن صحیح:

«✓ انتخاب این بازی»

این دکمه باید فقط برای بازی‌ای باشد که در حال مشاهده است.

مثلاً اگر کاربر روی «کلمه ممنوعه» است:

[✓ انتخاب این بازی]

بعد از کلیک:

[✓ انتخاب شد]

یا ترجیحاً دکمه به وضعیت Selected تغییر کند و غیرقابل انتخاب مجدد شود.

همزمان:
- بازی به Selected Games Chips اضافه شود.
- Chip شامل نام و × باشد.
- تعداد بازی‌های انتخاب‌شده در Header افزایش یابد.
- یک Micro Animation کوتاه اجرا شود.
- Chip با Motion نرم وارد Selected Games Bar شود.

6. جلوگیری از انتخاب تکراری
==================================================

کاربر نباید بتواند یک بازی را دوبار انتخاب کند.

اگر بازی قبلاً انتخاب شده است:
- دکمه «✓ انتخاب این بازی» نمایش داده نشود.
- وضعیت:
«✓ انتخاب شد»

نمایش داده شود.

اگر کاربر بازی دیگری را در Slider مشاهده کند:
- وضعیت انتخاب آن بازی مستقل باشد.

مثلاً:

بازی فعلی:
«کلمه ممنوعه»
→ انتخاب شده
→ [✓ انتخاب شد]

کاربر Swipe می‌کند:

«جاسوس»
→ انتخاب نشده
→ [✓ انتخاب این بازی]

==================================================

کاربر ابتدا:

این ترتیب همان ترتیب اجرای بازی‌ها باشد.

ترتیب باقی بازی‌ها حفظ شود.

10. ارتباط Slider با Selection
==================================================

Slider و Selection دو مفهوم جدا هستند.

Slider:
«دارم بازی را مشاهده می‌کنم»

Selection:
«این بازی را برای دورهمی انتخاب کرده‌ام»

بنابراین:
- تغییر Slide نباید انتخاب‌ها را تغییر دهد.
- انتخاب یک بازی نباید Slider را به بازی دیگری ببرد.
- حذف یک Chip نباید سایر بازی‌های انتخاب‌شده را حذف کند.
- Selection باید در تمام طول Session حفظ شود.

11. محدودیت تعداد بازی
==================================================

اگر سیستم محدودیت مشخصی برای تعداد بازی‌ها دارد، آن محدودیت را رعایت کن.

اگر مثلاً Maximum Selection = 9 باشد:
بعد از انتخاب 9 بازی:

Header:
«۹ بازی انتخاب شده»

و برای بازی‌های انتخاب‌نشده:
دکمه انتخاب غیرفعال شود.

پیام:
«همه بازی‌ها انتخاب شده‌اند»

اما اگر Maximum Selection در سیستم تعریف نشده، تعداد انتخاب را محدود نکن و اجازه بده همه بازی‌های موجود انتخاب شوند.

17. State Management
==================================================

Selection State را به صورت واقعی و مرکزی مدیریت کن.

ساختار منطقی:

selectedGames = [
  {
    id,
    name,
    icon,
    order
  }
]

Current Slider Game:

currentGameId

Actions:

SELECT_GAME(gameId)
REMOVE_GAME(gameId)
NEXT_GAME()
PREVIOUS_GAME()

Computed:

selectedCount
isSelected(gameId)
selectionOrder

Header باید selectedCount واقعی را نمایش دهد.

Chipها باید از selectedGames ساخته شوند.
